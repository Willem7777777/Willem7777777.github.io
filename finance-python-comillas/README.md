# Python for finance (Comillas)

Practice sessions from Foundations of Finance and Engineering Economy at Universidad Pontificia Comillas (Madrid).

- `p01-npv-and-irr.ipynb` - net present value and internal rate of return
- `p02-bond-basics.ipynb` - bond cash flows, pricing and yield
- `p03-yield-curve-calibration.ipynb` - fitting a yield curve
- `p04-bonds.ipynb` - bond exercises
- `p05-portfolios.ipynb` - portfolio construction and optimisation (group work)
