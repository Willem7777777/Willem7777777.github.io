# Data science (TB)

Notebooks from the TU Delft BSc course Data Science (Python).

- `obesity-data-analysis.ipynb` - own analysis of an obesity dataset (`data/dataobesitas.csv`)
- `week3-*` and `week4-*` - sampling, penguins data testing, linear and multiple regression, bootstrapping (adapted from course notebooks)
- `lecture2-*` and `lecture5-*` - grouping and joining, summary statistics, text data and graphs

Libraries: pandas, numpy, seaborn, matplotlib, scikit-learn, networkx.

- `practicum1-*` and `practicum2-*` - pandas, exploratory analysis, statistical tests and bootstrapping (Dutch)
