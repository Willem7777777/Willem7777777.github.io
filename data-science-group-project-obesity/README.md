# Group project: factors behind obesity types

Group project for TB242IA Intelligent Data Analysis (TU Delft BSc TPM, 2023). The report studies which lifestyle and external factors most influence obesity and its type, using the UCI "Estimation of obesity levels" dataset with regression analysis and one-sample t-tests in Python. Written in Dutch.

The report is `obesity-factors-report.pdf`. An individual analysis notebook on the same dataset is in `../data-science-tb/obesity-data-analysis.ipynb`.
