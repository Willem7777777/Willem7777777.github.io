# Java

Programming assignments from the first-year Java course (TU Delft).

- `SwansDucksgame3.java` - a Bulls-and-Cows style guessing game: the program draws a random 4-digit number with unique digits, validates each guess, and reports how many digits are in the right place (Swans) and in the wrong place (Ducks).
- `Speedrun.java` - a two-player dice game (first to 100 points) using a nested `Player` class, input validation and turn logic. Written together with a study partner.

Run with `javac Speedrun.java && java Speedrun`.
